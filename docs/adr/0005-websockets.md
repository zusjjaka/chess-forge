# ADR-0005: WebSockets

WebSocket выбран для передачи результатов анализа шахматного движка в браузер в реальном времени.

Стокфиш может постепенно улучшать оценку позиции, поэтому обычная модель request/response REST API неудобна для этой задачи.

Предполагаемый поток:

Browser - WebSocket - Backend - gRPC - Engine Service - Стокфиш

WebSocket позволяет серверу отправлять обновления клиенту без постоянного polling.
