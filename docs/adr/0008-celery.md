# ADR-0008: Celery

Celery выбран для выполнения фоновых задач.

Основные причины:

- выполнение задач вне client <-> http <-> server цикла;
- отдельные workers;
- повторные попытки;
- возможность независимо масштабировать workers.

Celery выбран для получения практического опыта работы с инструментом и дальнейшего применения.
