# ADR-0001: Microservices Architecture

Микросервисная архитектура выбрана по 2-м причинам:

1. Проект является практической площадкой для получения опыта разработки распределённых систем после работы с монолитными приложениями.

2. Отдельные части системы имеют различающиеся требования. Например, Engine Service потенциально требует отдельного масштабирования и взаимодействует с шахматным движком через gRPC.

Основной недостаток: увеличение сложности разработки, deployment и debugging.

Количество сервисов должно оставаться минимальным и оправданным их ответственностью.
