# ADR-0003: JWT Authentication

JWT выбран как основной механизм аутентификации между клиентом и сервером.

Основная причина - возможность передавать подтверждённую сущность пользователя между независимыми сервисами без необходимости централизованно хранить состояние каждой сессии.

Будут использоваться access и refresh токены с ограниченным временем жизни.
