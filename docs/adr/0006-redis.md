# ADR-0006: Redis

Redis выбран как высокопроизводительное временное хранилище.

Основные способы применения:

- кеширование;
- ограничение частоты запросов;
- временные данные;
- другие операции, требующие быстрого доступа.

Redis не является основной БД проекта. Вся основная информация хранится в PostgreSQL.

Redis также не используется как брокер сообщений для Celery, поскольку для этого выбран RabbitMQ.
