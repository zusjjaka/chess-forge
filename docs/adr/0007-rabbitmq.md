# ADR-0007: RabbitMQ

RabbitMQ выбран в качестве брокера сообщений для Celery.

Основное предназначние - выполнение фоновых задач, которые не должны блокировать HTTP request, например, отправка email писем.

RabbitMQ выбран вместо использования Redis в виду возможного усложнения бизнес логики веб-сайта

Предполагается использование очередей и отдельных Celery workers.
