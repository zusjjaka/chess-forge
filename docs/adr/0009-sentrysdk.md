# ADR-0008: Sentry-sdk

Sentry SDK выбран для мониторинга ошибок и состояния приложения.

Основное предназначение - автоматический сбор и отправка информации об ошибках в Sentry.

Основные причины:

* автоматический сбор исключений и ошибок;
* получение контекста ошибок;
* централизованный мониторинг;
* возможность отслеживать ошибки в production;
* сокращение времени на обнаружение и диагностику проблем.

Sentry SDK выбран в виду наличия практики работы с ним.
