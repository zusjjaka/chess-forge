# ADR-0004: gRPC

gRPC выбран для внутреннего взаимодействия с Engine Service.

Основные причины:

- строгий контракт через Protocol Buffers;
- вызов необходимых функций;
- поддержка streaming;
- эффективное бинарное представление сообщений;
- необходимость практического опыта работы с gRPC.

Предполагается использование server streaming для передачи промежуточных результатов анализа позиции.
