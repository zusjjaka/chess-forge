# Security

## 1. Password Hashing

* Пароли хешируются с использованием `Argon2id`.
* Пароли никогда не хранятся в явном виде.

## 2. Token Signing and Validation

* PyJWT отвечает за подпись и валидацию JWT токенов.
* **RS256** используется как алгоритм подписи.
* Access токены имеют короткий срок жизни и хранятся в замыкании на стороне frontend.
* Refresh токен хранится в Cookie с параметрами Http-only, Same-Site: Lax, Secure, Path=/api/v1/auth

## 3. SQL Injection

* **SQLAlchemy** используется как ОРМ.
* Экранированные запросы вместо обычной конкатенации данных в запрос

## 4. JavaScript Injection / XSS

* Данные пользователей предварительно валидируются.
* Недоверительные данные не внедряются на сайт.

## 5. Rate Limiting

API запросы ограничены по их частоте для предотвращения брутфорс атак.

* Ограничения устанавливаются по **IP адрессу**.
* auth endpoints также ограничены по **почте**.

## 6. CORS

* Внешние запросы разрешены только с официального клиентского сайта.

## 7. Input Validation

* **Pydantic** для валидации данных

Неправильные данные отклоняются до того, как будут сделаны какие-либо изменения

## 8. Environment Variables

* Конфигурации и секреты сохранены в локальных `.env` файлах.
