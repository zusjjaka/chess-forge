# Requirements

## Project Goal

ChessForge - приложение для создания и запоминания шахматных репертуаров.

Пользователь создаёт дерево вариантов, анализирует позиции с помощью шахматного движка и затем тренируется, воспроизводя сохранённые линии ходов.

Функциональность разделена на три категории:

- [Must-have Features](#must-have-features) - необходимы для первой рабочей версии.
- [Intermediate Features](#intermediate-features) - развитие продукта после MVP.
- [Future Features](#future-features) - идеи для дальнейшего развития.

---

# Must-have Features

## 1. Authentication

### Registration

Пользователь может:

- зарегистрироваться;
- указать email;
- указать пароль;
- получить письмо подтверждения.

### Email Verification

Пользователь может подтвердить email по ссылке из письма.

### Login

Пользователь может войти в аккаунт после регистрации.

### Password Reset

Пользователь может запросить восстановление пароля через email.

### Email change

Пользователь может сменить email с подтверждением через старый email.

---

## 2. Repertoires

Пользователь может создавать собственные репертуары.

Каждый репертуар представляет отдельное дерево шахматных вариантов.

Например:

- Я Белые 1.e4
- Я Черные 1.e4
- Я Черные 1.d4

Создание репертуара начинается со стандартной начальной позиции шахматной партии.

---

## 3. Repertoire Editor

Пользователь может:

- играть ходы на шахматной доске;
- автоматически добавлять сделанные ходы в текущую линию;
- отменять последний ход;
- выбирать существующую позицию в дереве;
- создавать новую ветку из существующей позиции;
- давать названия созданным вариантам;
- редактировать существующее дерево;
- сохранять репертуар.

Пример:

    1. e4 e5 2. Nf3 Nc6 3. Bb5 - "Итальянская партия"
                                \__ Nf6 - "Защита двух коней"
                                \__ Be6 - "Гучио Пиано"
---

## 4. Engine Analysis

Пользователь может анализировать текущую позицию с помощью Stockfish.

Система должна:

- отправлять позицию движку;
- получать результаты анализа;
- обновлять оценку позиции в реальном времени;
- отображать основные варианты движка.

Количество отображаемых вариантов и другие параметры анализа могут зависеть от подписки пользователя в будущем.

---

## 5. Training

Пользователь может начать тренировку с любой выбранной позиции в собственном репертуаре.

Перед началом тренировки:

- пользователь выбирает репертуар;
- пользователь выбирает стартовую позицию;
- пользователь может указать варианты, которые необходимо исключить из текущей тренировки.

Система случайно выбирает одну доступную конечную линию.

После этого пользователь должен воспроизвести выбранную последовательность ходов.

Пользователь должен воспроизвести именно эту последовательность.

Любой ход, отличный от ожидаемого, означает провал текущей попытки.

Повторная попытка в рамках той же попытки не предоставляется.

---

## 6. Training Session

Каждая попытка тренировки представляет отдельную Сессию Тренировки.

Сессия Тренировки содержит состояние конкретной попытки, включая:

- репертуар;
- стартовую позицию;
- выбранную линию;
- исключённые варианты;
- ходы пользователя;
- состояние тренировки;
- результат.

Результат попытки может быть:

- УСПЕХ;
- ПРОВАЛ.

После завершения тренировки пользователь может:

- начать новую тренировку;
- просмотреть результат текущей попытки.

---

# Intermediate Features

## 1. Repetition

Добавить систему интервального повторения, которая автоматически определяет, какие варианты необходимо повторить.

Система должна учитывать историю попыток пользователя и постепенно увеличивать интервал для хорошо изученных вариантов.

Пользователь должен видеть:

- какие варианты необходимо повторить;
- какие варианты изучены хорошо;
- прогресс изучения.

Конкретный алгоритм будет определён отдельно.

---

## 2. Opening Database

Создать базу распространённых дебютов и вариантов.

Пользователь сможет:

1. выбрать существующий дебют;
2. добавить его в свой репертуар;
3. изменить его под собственный стиль игры.

Предварительно предполагается, что пользователь получает независимую копию дебюта, которую может свободно изменять.

---

## 3. Improved Training Selection

Добавить более интеллектуальный выбор линий вместо полностью случайного выбора.

Возможные факторы:

- история попыток;
- количество ошибок;
- сложность варианта;
- время с последнего повторения;
- текущий уровень запоминания.

---

# Future Features

## 1. Chess.com Integration

Подключение аккаунта Chess.com и получение истории партий.

Система сможет анализировать партии пользователя и собирать статистику по дебютам.

---

## 2. Lichess Integration

Аналогичная интеграция с Lichess.

---

## 3. Opening Analytics

На основе сыгранных партий показывать:

- количество партий в конкретных дебютах;
- победы;
- поражения;
- ничьи;
- процент побед;
- статистику по конкретным вариантам.

Повторный анализ будет доступен повторно через определенный промежуток времени.

---

## 4. Subscription

Добавить платную подписку.

Возможные ограничения и возможности:

- максимальный размер репертуара;
- максимальное количество узлов дерева;
- большее количество вариантов Стокфиша;
- дополнительные функции анализа.

Конкретная модель подписки будет определена позже.

---

## 5. Endgame Training

Добавить отдельный режим изучения и тренировки эндшпилей и матовых шаблонов против Стокфиш.

---

# Out of Scope for MVP

Следующие функции не должны блокировать разработку первой версии:

- Интеграция с Chess.com;
- Интеграция с Lichess;
- анализ дебютов;
- интервальное повторение;
- подписки;
- тренировка эндшпилей;
- сложный выбор линий.

MVP должен в первую очередь доказать работоспособность основного цикла:

    Create Repertoire
    ->
    Build Variations
    ->
    Save
    ->
    Select Position
    ->
    Train
    ->
    Success / Failure
