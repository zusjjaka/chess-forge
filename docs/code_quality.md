# Code Quality

Для контроля качества кода и автоматизации разработки используются следующие инструменты.

## Ruff

**Ruff** используется для статического анализа и форматирования Python-кода.

* Проверяет код на потенциальные ошибки и нарушения стиля.
* Автоматически исправляет часть найденных проблем.
* Форматирует исходный код в едином стиле.

## Mypy

**Mypy** используется для статической проверки типов.

* Проверяет соответствие типов в Python-коде.
* Помогает обнаруживать ошибки, которые могут возникнуть во время выполнения.
* Позволяет поддерживать строгую типизацию проекта.

## Pytest

**Pytest** используется для автоматического тестирования.

* Проверяет корректность работы отдельных компонентов.
* Позволяет писать unit- и integration-тесты.
* Автоматически запускает набор тестов и сообщает об ошибках.

## Pre-commit

**Pre-commit** используется для автоматического запуска проверок перед созданием Git-коммита.

Перед коммитом он запускает настроенные проверки качества кода, включая Ruff, Mypy и Pytest. Это позволяет обнаруживать проблемы до того, как изменения попадут в репозиторий.
